# 이순신 한자학습 XR — 수정판

## 주요 수정
- 수평선과 섬이 포함된 바다 사진의 반복 텍스처 제거: 단일 절차적 파도 수면
- 1막: GLB 판옥선 12척을 4×3 대형으로 배치, 카메라 근접 조정
- 3막: 이순신 GLB를 기함 갑판에 부착해 배와 함께 움직이도록 조정
- 4막: 좌우 경사진 입체 섬과 중앙의 거센 파도 구현
- 판옥선 계수기는 1막에만 표시

## 주의
외부 GLB 및 Three.js CDN에 인터넷 연결이 필요합니다. 실제 GLB의 갑판 위치와 방향은 브라우저 화면을 보고 추가 미세 조정이 필요할 수 있습니다.
