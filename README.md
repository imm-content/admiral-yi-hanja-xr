# 이순신 한자학습 XR — 수정판

5막 한자학습과 3D 체험. `index.html`을 GitHub Pages 저장소 루트에 올립니다.

- 제1막: 판옥선 12척, 3열×4행, 실제 GLB 개체로 생성
- 제2막: 11척 후방, 대장선 전진, 장군 탑승, 음성
- 제3막: 대장선 갑판의 장군과 결의 음성
- 제4막: 원본 바다 텍스처 속 실사풍 좌우 섬과 빠른 물살, 추가 저폴리곤 섬 없음
- 제5막: 승리 함대

## 자산
- 판옥선: https://imm-content.github.io/admiral-yi-history-xr/Sketchfab_panokseon.glb
- 장군: https://imm-content.github.io/admiral-yi-history-xr/admiral-yi-sunsin.glb
- 바다: https://imm-content.github.io/admiral-yi-battle-xr/uldolmok-sea-texture.png

외부 원본 파일을 실시간으로 읽습니다. 원본 파일 URL과 CORS 설정이 유지되어야 합니다.

## 검증 주의
코드의 구문과 구조는 확인했으나 브라우저의 GLB 실물 크기·방향 및 최종 화면은 아직 직접 검증하지 못했습니다. 장군 방향이 반대이면 `↻ 장군 방향` 버튼으로 전환하세요.
