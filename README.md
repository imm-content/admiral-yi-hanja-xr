# 이순신 한자학습 XR

**열두 척의 기적, 한문으로 만나다 · 체험형 학습관**

이 프로젝트는 이순신 장군과 명량해전의 이야기를 바탕으로 **한자 원문, 한글 독음, 뜻풀이, 글자별 설명 및 확인 문제**를 학습하는 웹 콘텐츠입니다. 판옥선 3D 모델, 움직이는 바다, 울돌목 연출과 음성은 학습을 돕는 보조 요소입니다.

## 체험하기

- 공개 사이트: https://imm-content.github.io/admiral-yi-hanja-xr/
- GitHub 저장소: https://github.com/imm-content/admiral-yi-hanja-xr

> **배포 안내:** `admiral-yi-hanja-xr-hanja-learning-five-acts.html`은 제작한 HTML 파일명입니다. 이를 저장소 루트의 `index.html`로 배포하면 위 공개 사이트의 기본 화면이 됩니다. 기존 `index.html`은 교체 전에 반드시 백업하십시오. 별도 테스트가 필요하면 `test3.html` 등 다른 이름으로 올려 먼저 확인할 수 있습니다.

## 다섯 막 구성

| 막 | 한자 원문 | 한글 독음 | 체험 연출 |
|---|---|---|---|
| 제1막 · 희망의 열두 척 | 今臣戰船 尙有十二 | 금신전선 상유십이 | 판옥선 12척이 한 척씩 등장 |
| 제2막 · 죽을힘을 다하여 | 出死力 拒戰則猶可爲也 | 출사력 거전즉유가위야 | 대장선이 앞으로 나서고 장군 삽화 등장 |
| 제3막 · 필사의 각오 | 必死則生 必生則死 | 필사즉생 필생즉사 | 선두 대장선과 장군의 결의 |
| 제4막 · 울돌목의 물살 | 一夫當逕 足懼千夫 | 일부당경 족구천부 | 함선을 숨기고 해협과 물살을 강조 |
| 제5막 · 명량해전 | 鳴梁海戰 | 명량해전 | 전투 효과음과 역사 내레이션 |

각 막에는 한자 뜻풀이, 글자별 학습 내용 및 객관식 확인 문제가 포함됩니다. 제5막의 장면 내 음성은 긴 한자 자막 대신 명량해전의 역사적 배경을 설명하도록 구성되어 있습니다.

## 주요 기능

- **GLB 12개 개별 로딩:** `assets/panokship01.glb`부터 `assets/panokship12.glb`까지 각각 불러옵니다. 판옥선 복제용 `clone()`에 의존하지 않습니다.
- **3D 바다:** Three.js로 바다 표면과 파도 효과를 표현합니다.
- **한자학습:** 각 막의 원문, 독음, 뜻풀이, 글자별 설명 및 확인 문제를 제공합니다.
- **음성:** 브라우저의 한국어 음성 합성(TTS)을 사용하며 남성 음성을 우선 선택합니다. 기기에 적절한 남성 음성이 없으면 장군의 남성 목소리가 보장되지 않습니다.
- **전투 효과:** 제5막에 웹 오디오 기반 효과음을 사용합니다.

## 파일 구성

```text
admiral-yi-hanja-xr/
├── index.html                          # 공개 사이트 기본 파일(교체 시 백업 권장)
├── README.md                           # 프로젝트 안내
├── assets/
│   ├── panokship01.glb
│   ├── panokship02.glb
│   ├── ...
│   ├── panokship12.glb
│   ├── admiral.svg                      # 장군 삽화
│   └── ...                              # 기존 자료 유지
└── test3.html                          # 선택: 검증용 HTML
```

실제 HTML은 외부의 Three.js CDN과 바다 이미지 URL을 사용합니다. 따라서 최초 실행 시 인터넷 연결이 필요합니다.

## GitHub Pages 배포

1. `assets/`에 판옥선 GLB 12개가 있는지 확인합니다.
2. 기존 `index.html`은 백업합니다.
3. 수정 HTML을 먼저 `test3.html`로 업로드해 다섯 막의 화면과 음성을 확인합니다.
4. 정상 작동을 확인한 후 수정 HTML을 `index.html`로 배포합니다.
5. GitHub Pages 배포 완료 후 공개 사이트에서 확인합니다.

## 사용 환경과 유의사항

- PC의 최신 Chrome 또는 Edge 브라우저 권장
- GLB 파일이 크므로 첫 로딩에 시간이 걸릴 수 있음
- 한국어 TTS 음색과 재생 여부는 운영체제·브라우저의 설치 음성에 따라 달라짐
- 제4막의 섬·해협 연출은 교육용 시각화이며 실제 지형을 정밀 복원한 모델이 아님
- 제5막의 전투 연출은 역사 교육용 축약 표현이며 실제 전투의 세부 장면을 정확히 재현한 것은 아님
- 외부 3D 모델·이미지의 저작권과 이용 허락은 원본 출처에서 별도로 확인 필요
