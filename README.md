# 이순신 한자학습 XR — 제1막 1척 검증판

이 파일은 성공한 `admiral-yi-battle-xr`의 `index(7).html`을 기반으로 만든 **판옥선 1척 기준 시험판**입니다.

- 원본의 판옥선 GLB 로딩, `boatRoot`, 정규화, 카메라, 파도 셰이더 및 항해 애니메이션을 유지했습니다.
- 제목과 체험 버튼을 제1막으로 변경했습니다.
- 바다 텍스처는 원본 저장소의 `uldolmok-sea-texture.png`를 직접 불러옵니다.
- 적선·포격 관련 버튼은 화면에서 숨겼습니다.
- 아직 12척 복제, 5막 통합을 수행하지 않았습니다.

## 사용법
1. ZIP 압축을 풀고 `index.html`을 `admiral-yi-hanja-xr` 저장소 루트에 업로드합니다.
2. GitHub Pages를 열고 `제1막 체험하기`를 누릅니다.
3. 정상 작동하는 원본과 **판옥선 한 척의 크기와 바다 비율**을 비교합니다.

GLB와 PNG는 외부 GitHub Pages URL에서 로드하므로 인터넷 연결이 필요합니다.

**검증 한계:** 정적 소스 확인만 완료했으며, 원격 리소스를 실제 브라우저에서 렌더링한 결과는 확인하지 못했습니다.
