# 이순신 한자학습 XR | Admiral Yi Hanja XR

명량해전을 배경으로 한문 명구를 배우는 브라우저 기반 체험형 콘텐츠입니다.

## 체험 장면
1. **今臣戰船 尙有十二** — 신에게는 아직 전선 열두 척이 있습니다. (한 척에서 열두 척으로 등장)
2. **出死力 拒戰則猶可爲也** — 죽을힘을 다해 막아 싸운다면 아직 해볼 만합니다. (전투 시뮬레이션)
3. **必死則生 必生則死** — 죽기를 각오하면 살고, 살려고만 하면 죽는다. (결의와 한자 학습)
4. **一夫當逕 足懼千夫** (일부당경 족구천부) — 한 사람이 좁은 길목을 지키면 천 사람도 두렵게 할 수 있다. (울돌목의 좁은 해협·거센 조류·적선 접근 연출)
5. **鳴梁海戰** — 명량해전 승리와 복습 퀴즈

> 역사적 문구는 교육 목적의 발췌·풀이이며, 전투 화면은 실제 역사 기록의 정확한 재현이 아닌 학습용 연출입니다.

## 실행
`index.html`을 브라우저로 열거나 GitHub Pages를 켜면 됩니다. 설치 및 외부 라이브러리 불필요.

- PC: 버튼 클릭 / 좌우 방향키로 장면 전환
- 모바일: 버튼 터치, 지원 기기에서 진동 효과
- '음성 읽기': 브라우저 음성 합성 기능 사용 (음성 및 발음은 기기에 따라 달라질 수 있음)
- '영상 저장': 브라우저에서 지원되는 경우 애니메이션을 WebM으로 녹화

## 파일
- `index.html`: 본문, 애니메이션, 한자 학습, 퀴즈, 녹화 기능
- `assets/sea.svg`: 바다 배경 삽화
- `assets/panokseon.svg`: 판옥선 삽화
- `assets/admiral.svg`: 이순신 장군을 상징하는 창작 일러스트
- `assets/poster.svg`: 대표 썸네일

## GitHub Pages
Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)` → Save.

공개 주소: `https://imm-content.github.io/admiral-yi-hanja-xr/` (계정명이 imm-content일 경우)

## 권리 및 참고
SVG 그림과 코드는 이 프로젝트를 위해 새로 제작되었습니다. 외부 영화 영상·음악은 포함하지 않았습니다. 교육·출판 활용 시 문구 출처와 역사적 맥락을 별도 검증하는 것을 권장합니다.
