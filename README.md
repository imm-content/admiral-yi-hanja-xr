# 이순신 한자학습 XR — 판옥선 12척 크기 수정 시험판

## 기준
- `admiral-yi-battle-xr/index.html`의 GLB 정규화 방식(`k=1.45/max(size)` 및 `ship.position.sub(center*k)`)을 사용합니다.
- 원본의 파도 셰이더와 `uldolmok-sea-texture.png`를 사용합니다.
- 원본에서 한 척에 적용한 `boatRoot.scale=.65`를 함대 배치에 맞게 `.27`로 변경했습니다.
- 3열×4행의 서로 다른 월드 좌표에 12척을 배치합니다.

## 확인
1. `index.html`을 GitHub Pages에 업로드합니다.
2. `진단: 1척` → `진단: 3척` → `진단: 12척` 버튼을 누릅니다.
3. `3D 진단 정보`를 펼쳐 실제 크기와 좌표를 확인합니다.

**주의:** 원격 GLB의 브라우저 렌더링 검증은 완료되지 않았습니다. 따라서 완성본이 아닌 1막 크기·배치 확인용 시험판입니다. 제2~5막의 장군/해협 연출은 아직 미완성입니다.
